# Optional music

The public source repository excludes third-party music files. The game loads these optional paths if you add audio you have permission to use:

- `BTD_Warzone_2100_Inspired.mp3` — menu music
- `Martin_Severn_-_Warzone_2100_-_1._Nuclear_Silence_(mp3.pm).mp3` — in-match music

Without these files, the game runs normally with no background music. The Windows playtest ZIP assembled from the original project folder includes the audio currently used in the game.
